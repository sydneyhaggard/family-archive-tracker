# Related People - New Features

## Description

I want to add new fields to the Related People entries. Some have already been created, so check to see if a similar field has already been created.

## Fields to add from the GEDCOM import

- Full Name
- Birth date and location
- Death date, location, and burial location
- Parents (table field with names, birth dates, birth locations, death dates, and death location of parents. Link out to each parent. Some related people entries may have both birth parents, adoptive parents, or step-parents. Be sure to list each with their parental status, if possible.)
- Siblings (table field with names, birth dates, birth locations, death dates, and death location of siblings. Link out to each sibling)
- Spouses (and link out to the related spouse)
- Residences (table field)
- Military service details (date of enlistment, date they were discharged, rank, and company)
- Sources (link out to the information sources if possible)
