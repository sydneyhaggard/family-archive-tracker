# Related People - New Features

## Description

I want to add new filtering to Related People. Create a sidebar on the left that displays filterable criteria

## New filtering criteria

- **By Birth Year Range**: Allow users to filter people based on a range of birth years (e.g., 1900-1950).
- **By Death Year Range**: Similar to birth year, but for death years.
- **By Relationship Type**: Filter people based on their relationship to the user (e.g., parent, sibling, child, spouse).
- **By Linked Archive Items**: Filter people who are linked to a certain number of archive items (e.g., more than 5 items).
- **By Date Added**: Filter people based on when they were added to the database (e.g., last 30 days, last year).
- **By Last Name**: Filter people based on their last name (e.g., "Haggard", "Laurien", etc.). List out all last names in the database as selectable options.
- **By Custom Tags**: Allow users to add custom tags to people and filter based on those tags.

## User Interface Changes
- Add a collapsible sidebar on the left side of the Related People page.
- Each filtering criterion should have appropriate input controls (e.g., date pickers for year ranges, dropdowns for relationship types, checkboxes for last names).
- Include a "Clear All Filters" button to reset the filters.
- Display the number of active filters applied.
- Update the people list in real-time as filters are applied or removed.
- Ensure the UI remains responsive and user-friendly on both desktop and mobile devices.
- Add a section on the Home Dashboard to display the total number of people in the Related People database, along with quick links to apply common filters (e.g., "Recently Added", "With More Than 5 Items", etc.).
- Implement loading indicators while filters are being applied to enhance user experience.
- Ensure accessibility standards are met for all new UI components.
